# 校园招生资料与审阅规则

材料来自本地 RAG 知识库中的山东大学（威海）2024 级智能导航特色班、计算法学实验班招生简章。
仓库只保存选定段落，不复制完整 DOCX、报名群、联系人或个人名单。
来源见 [manifest](../app/fixtures/campus/manifest.json)，它记录的是离线材料快照，不是在线政策查询结果。

`paragraphs.index` 是 `word/document.xml` 内所有 `w:p` 的一基序号，包含空段和表格内段落。
`source_sha256` 对应原始 DOCX；`excerpt_sha256` 对应本仓库 Markdown 的 UTF-8 字节。
运行时将摘录哈希与解析文本哈希核对，审阅包把原文证据关联到原 DOCX 段落。
原始 DOCX 不随仓库分发，运行时不会重新打开原文件验证其哈希。

## 能检查什么

- 报名对象、报名时间、招生名额等关键字段缺失。
- 同一份材料中出现不同招生名额；面试入围比例不进入名额规则。
- “中午14点”这样的表述歧义；报名时间没有显式年份。
- 材料年份早于显式传入的审阅年份。
- 工作流检测到的标量冲突。

这些检查产生问题清单，不替代人工判断。无命中项时仍保留 `needs_human_review`。
目前不提供审批账号、审核签名或发布功能；`as_of` 只用于年份检查，不是完整日期解析器。

## 离线提取的范围

`MockLLM._campus_admission` 按段落关键词匹配这两份已知格式的材料，输出连续原文片段。
它不推断个人资格，不把条件拆成失去例外条款的短句，也不自动补全日期。
其他格式需要补充解析规则或接入真实模型，并独立评估结果。

`app/services/campus_review.py` 在通用 Pipeline 结果之上生成审阅包。
通用 `analyze` CLI 和 API 也认识 `campus_admission`，但只有校园命令额外执行来源匹配与业务检查。
学校材料的权利归原作者；本仓库的 MIT 代码许可不授予原文再分发权。
